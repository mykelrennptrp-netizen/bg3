# BG3 Theorycraft Hub

This is my BG3 build theorycrafting / min-maxing project.

## Folders
- Builds/   = my build guides (Markdown)
- Data/     = any structured data (csv/json/etc.)
- Sources/  = links and notes (bg3.wiki, data hub, etc.)

## How to use this
1) Start in Builds/
2) Each build has: leveling plan, key items, key breakpoints, and sources.
